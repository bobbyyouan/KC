# KC Pavement Analysis Platform

## A Civil Engineering Database for the Kansas City Metropolitan Area

Built by Bobby Youan and Danny Will with collaboration from Overland Park Interns at BHC.

### Features

✅ **13+ Cities Covered** - Kansas City Metro municipalities with detailed specifications
✅ **Pavement Calculator** - 30-year lifecycle cost analysis
✅ **Pavo AI Assistant** - Intelligent chat with voice input and file upload
✅ **City Admin Panel** - Add, edit, and manage city specifications (Bypass Mode)
✅ **Interactive Maps** - Clickable city markers for quick access
✅ **PDF Export** - Professional analysis reports
✅ **Cloud Sync** - Real-time data synchronization

### Tech Stack

- React 18
- Framer Motion (animations)
- Recharts (data visualization)
- jsPDF (PDF generation)
- Tailwind CSS
- Firebase (Cloud database)

### Getting Started

```bash
npm install
npm start
```

### Data Sources

- APWA Standards
- KDOT (Kansas Department of Transportation)
- MoDOT (Missouri Department of Transportation)
- Municipal Engineering Departments
- Historical Bid Data
